02 · The bottom line

如果只有 60 秒，读这段

TL;DR

三层判断 · 一页纸结论

  1. 四家技术地图：每家有不可复制的护城河。SK Hynix 的 MR-MUF + NAMICS 独家配方让 12-Hi/16-Hi HBM 散热翻倍；Samsung 是唯一三全栈（DRAM/NAND/HBM）+ 自家 4nm Foundry 做 base die；Micron HBM3E 比对手能效低 30% + 早签 Adeia hybrid bonding 协议（IP 风险最小）+ ASIL-D 车规独家；SanDisk+Kioxia 在 NAND 用 BiCS+CBA 已 demo 1000 层路径。韩国二虎的隐藏短板是 hybrid bonding IP 不在自己手里——一头被 Adeia 卡，一头被 YMTC 卡。
  2. HBM 周期是后视镜，但信号其实早就在。最早的硬信号是 2022-03 到 2022-08 的"四层收敛"——Chinchilla 论文（理论）+ NVIDIA GTC Hopper（卖方战略）+ A100 缺货（供应链）+ Stable Diffusion（消费产品）同时发生。Dylan Patel 2022-12 起在 Semianalysis 写 HBM 瓶颈，比大行早 28 个月。市场确认日是 2023-05-24 NVIDIA FY24Q1 业绩盘后 +26%。从信号收敛到市场确认 = 14 个月，这是真正的入场窗口。
  3. 下一波信号已经在收敛。CXL（确定增量）+ SRAM 推理替代（HBM 真威胁）+ 3D DRAM（5 年后下一代 HBM 核）三股力量同时在动。最确定的是 CXL（NVIDIA Vera CPU 2026 H2 原生支持 + Samsung Pangea v2 实测 +10.2x），最值得防御的是 SRAM 推理（NVIDIA 200 亿美元收购 Groq + OpenAI-Cerebras 100 亿美元/3 年），最值得长线观察的是 3D DRAM（Samsung ISSCC 2026 已展示 16Gb 4F² VCT）。
03 · The Tech Map

技术地图 · 四家的护城河

SK Hynix、Samsung、Micron、SanDisk+Kioxia——四家的技术坐标系完全不同。 不要把它们当成竞争者，要当成专业化分工：HBM 是韩国二虎与 Micron 的三国杀， NAND 真正的鼻祖是 BiCS（SanDisk+Kioxia）。

SK Hynix MR-MUF 为什么是真壁垒
MR-MUF（Mass Reflow-Molded Underfill）一次回流焊整个 stack 的 bumps + 一次注入液态环氧。对比 TC-NCF 一层一层压，MR-MUF 是批处理。 关键数字：MR-MUF 用的环氧模塑料（EMC）热导率约为 NCF 的 2 倍；HBM2E 散热较 HBM2 提升 36%；MR-MUF 让 thermal dummy bump 数量比 TC-NCF 多 4 倍。 与 NAMICS（日本材料商）联合开发的专属环氧配方——专利 + 材料 + 设备（Hanmi TC bonder）三重绑定。这就是为什么 NVIDIA GB300 12-Hi HBM3E 独家给 SK Hynix。

04 · The IP Map

专利护城河 · 韩国二虎的隐藏短板

技术对比表里看不到的一件事： 韩国二虎在 HBM 装配 + DRAM 工艺有一手好牌，但 hybrid bonding 基础 IP 不在自己手里—— 一头被 Adeia（美国）卡，一头被 YMTC（中国）卡。这是 HBM4E 之后的隐藏风险点。

SK Hynix · 不可复制三件套

1. MR-MUF + NAMICS

  • 材料级专利 + know-how
  • NAMICS 全球独家供货配方
  • 12-Hi/16-Hi 良率天然占优
  • NVIDIA Hopper/Blackwell/Rubin 长期偏好
Samsung · 垂直整合

2. Memory + Foundry

  • 1c DRAM + 4nm Foundry base die
  • 无需 TSMC 接刀
  • DTCO 跨部门联合优化
  • iPhone 17/18 LPDDR 主供
Micron · IP 干净 + 能效

3. 早签 Adeia

  • 2022 年签 hybrid bonding 协议
  • HBM3E 能效 −30% pJ/bit
  • 1γ "少 EUV" 工程哲学
  • ASIL-D 车规独家
SanDisk + Kioxia · NAND 鼻祖

4. BiCS + CBA

  • BiCS8 218L 18.3 Gb/mm²（最高）
  • JV 联营 32% 全球 NAND 产能
  • MSA-CBA 路径已 demo 千层
  • HBF（与 SK Hynix 合作）
韩国二虎的"hybrid bonding IP 风险"
未来 HBM4E（20+ 层）必走 hybrid bonding，但：
• Adeia (前 Xperi)持有 DBI（Direct Bond Interconnect）基础专利——Micron / SK Hynix / Sony / YMTC / UMC 已授权；Samsung 是唯一未明确授权的大厂
• YMTC（中国）持有量产层面专利量第一——Samsung 据传已向 YMTC 授权用于 V10+ NAND 与 HBM4 16-Hi。这是中国对韩国的反向技术依赖反转
• TSMC持有大量 hybrid bonding 设备/工艺专利——韩国厂的 base die 必须经 TSMC 才能用 5nm/3nm
四家技术坐标系不同，
但有一件事相同：信号都已经在了，只是当时没人看。
05 · The Hindsight

后视镜 · HBM 周期的早期信号

AI/HBM 超级周期被市场全面确认是 2024-2025，但真正的硬信号早在 2022-03 到 2022-08 就出现了。 这一节回溯整条信号传播链——从学术到大众到大行—— 建立"如何在下次预测前先看到"的方法论。

06 · The Framework

方法论 · 识别下场超级周期的 5 层信号

回溯告诉我们的最深刻教训：不要追单一爆点，要追"分布式信号同向收敛"。 把信号按时间和领域分成 5 层（L0 到 L4），每层有自己的检测方式。 理想入场点是 L1-L2 之间，最迟 L3 收敛时。

5 层信号 · 出现顺序与检测方式

L0
学术 / 理论信号 · 最早，T-3 到 T-1.5 年

当某领域出现一篇"花更多 X 就能换更多 Y"的可量化论文（如 Chinchilla），意味着投入有清晰的 ROI 函数 → 大资本会跟进。

检测方式：盯 arxiv 月度发文增长率突然加速的子领域（cs.LG / cs.CV 等）
L1
基础设施供应商信号 · T-2 到 T-1 年

(a) 垄断性上游供应商已经在某产品上"下注式"扩产（如 SK Hynix 在 2022 年明显领先 Samsung 量产 HBM3）。 (b) 卖方公司 CEO 反复在 keynote 强调一个新叙事但市场没买账（Jensen 在 2017、2018、2020 反复说 AI factory，到 2023 才反应）。

检测方式：上游设备订单（ASML / Applied Materials / Lam）+ 财报里 capex 指引 + 客户认证状态；keynote 文本做 5 年差分
L2
商业可行性信号 · T-1.5 到 T-0.5 年

第一个商业化产品出现，并被一小部分用户重度付费使用：Github Copilot 2021、DALL-E 2 2022-07、Stable Diffusion 2022-08——都先于 ChatGPT 验证了"愿意付钱"。

检测方式：看小型 SaaS 产品的 retention + 单用户付费金额，而不是看注册数
L3
供应链张力信号 · T-1 到 T-0 年

(a) lead time 持续延长 + "二手价高于一手价"（A100 在 2021-2022）。 (b) 真正的瓶颈从"芯片"转到上游材料 / 封装 / 内存——当大家从"GPU 不够"→"HBM 不够"→"CoWoS 不够"，意味着赢家从下游往上游迁移，上游公司还没被定价，是套利窗口。

检测方式：渠道商财报 + Reddit/HN 求货帖；Semianalysis、SemiWiki、TrendForce、DigiTimes 关键词频率
L4
资本拐点信号 · T-0.5 到 T+0 年（"市场确认"前最后窗口）

超大规模厂的 capex 同比增速从 30% 突变到 70%+——Hyperscaler capex 在 2023Q2 起加速，是结构性而非周期性变化，是最强的"现金流确认"。

检测方式：每季度 Alphabet/AWS/Microsoft/Meta/Oracle capex 指引 — 关注指引上调次数比绝对额更重要

7 项 Checklist · 每月对一个候选领域做诊断

  1. arxiv 月度发文 / 关键词频率突变了吗？
    L0 信号。突然加速的子领域往往是新周期的种子。例如 2022 年 cs.LG 上 transformer scaling 论文的频率。
  2. 学术界有没有出现"scaling law"型可量化论文？
    L0 信号。"花 X 换 Y"的清晰 ROI 函数 = 大资本能算账了。Chinchilla 是 HBM 周期的开关。
  3. 卖方公司的 keynote 关键词词频在变化吗？
    L1 信号。NVIDIA GTC、Apple WWDC、微软 Build、Google I/O 文本做 5 年差分，看哪个词频突然飙升。
  4. 是否有第一个小规模商业产品已经做出 retention？
    L2 信号。看付费 retention 而非注册数。Github Copilot、Cursor、Perplexity 等是 LLM 周期的早期实证。
  5. 上游设备 / 材料 / 包装公司的 lead time 在拉长吗？
    L3 信号。ASML、Applied Materials、Lam Research、Tokyo Electron 等的订单簿与交期变化。
  6. 超大规模厂的 capex 指引上调次数在增加吗？
    L4 信号。频率比绝对额重要——一个季度内多次上调说明真实需求超过预期。
  7. Semianalysis / 同类深度分析师在写哪些主题？
    综合信号。Dylan Patel 等专业分析师 28 个月领先大行——他们的写作主题就是早期信号本身。
触发阈值
• 3 项以上同向变化 → 进入观察窗口
• 5 项以上同向 → 进入入场窗口
• 6-7 项同向 → 已经是中后期，跑赢市场难度上升
• 大行升级 / 共识形成= 滞后指标，是减仓信号而非加仓信号
"市场确认"是一次事件。
"信号收敛"是一段窗口。
钱在窗口里赚，不在事件后追。
